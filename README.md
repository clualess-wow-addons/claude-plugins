# Claude Code skills

Skills for [Claude Code](https://claude.com/claude-code) used across the [clualess-wow-addons](https://github.com/clualess-wow-addons) projects.

## Skills

| Skill | Description |
|---|---|
| [`wow-classic-addon-developer`](skills/wow-classic-addon-developer) | Expert reference for building, debugging, and optimizing WoW Classic Era (1.15.x) Lua addons — API availability, taint/combat lockdown, events, Ace3, SavedVariables, TOC files, and 16 deep-dive reference docs. |

## Install

Copy a skill folder into your project's `.claude/skills/` directory (or `~/.claude/skills/` for global use):

```bash
cp -r skills/wow-classic-addon-developer /path/to/project/.claude/skills/
```

Claude Code picks it up automatically on the next session.
